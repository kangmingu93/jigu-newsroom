개인정보처리방침

시행일: 2026년 10월 6일

무엇을 하는 도구인가

지구 편집국은 운영자 본인의 Google 계정으로 Blogger API에 접근해, 운영자 본인의 블로그에 글 초안을 만들고 예약 발행·발행 상태 확인을 하는 개인용 도구입니다.

사용하는 정보

  • Blogger API 권한(https://www.googleapis.com/auth/blogger)으로 운영자 블로그의 글을 만들고, 고치고, 예약하고, 상태를 읽습니다.
  • 인증 토큰은 운영자 본인의 컴퓨터에만 저장하며, 제3자에게 전송·판매·공유하지 않습니다.
  • 다른 사람의 개인정보를 수집하지 않습니다.

Google 사용자 데이터

Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

권한 철회

언제든 Google 계정 권한 화면에서 이 앱의 접근을 철회할 수 있습니다.
